Artelnics/OpenNN changes: The first ECG channel of record chf07 was decoded
from WFDB format 212. Interior heartbeats were segmented at annotation
midpoints, interpolated to 140 values, standardized per beat, and rounded to
eight decimal places. The 5,000-row subset contains all selected abnormal
beats and a deterministic sample of normal beats. Each row contains 140
values followed by label 1 for normal or 0 for non-normal. In this Neural
Designer package, OpenNN's chf07_heartbeats.csv is stored under the legacy
project path ecg_normal.csv. test_indices.csv preserves OpenNN's deterministic
1,000-row test split.

The complete provenance, source-file hashes, class counts and reproduction
script copied from OpenNN are in OPENNN-SOURCE.md.
