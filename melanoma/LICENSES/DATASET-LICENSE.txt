Artelnics/OpenNN changes: The package contains the first 50 benign images and
the first 52 melanoma images after sorting the official ISIC 2016 Part 3
training identifiers within each class. Images were resized to 300 by 300
pixels with Lanczos resampling and converted to 24-bit BMP. The files are
stored in melanoma_dataset_bmp/benign and melanoma_dataset_bmp/malignant so
the existing Neural Designer project path remains valid. manifest.csv records
the original identifiers, labels and source archive members.

hashes and reproduction script copied from OpenNN are in OPENNN-SOURCE.md.
